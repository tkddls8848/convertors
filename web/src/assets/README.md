# HWPX 생성 검증용 기본 패키지

`Skeleton.hwpx`는 python-hwpx의 빈 문서 템플릿을 수정 없이 가져왔다.

- 저작권: Copyright 2025-2026 airmang
- 라이선스와 고지: `python-hwpx.LICENSE`, `python-hwpx.NOTICE`

생성기는 실행 시 원본의 빈 쪽과 메타데이터를 교체한다. 원본 템플릿의
스타일·문서 설정을 재사용하며, 배포 전 실제 한글 열기 검증이 필요하다.
