# 이 사이트는 검색 노출도, AI 학습·요약용 수집도 원하지 않는다.
#
# 이 변환기는 사내용 도구다. 색인될 이유가 없고, 크롤러가 오면 정적 자산(PDF.js 의
# cmap·글꼴·wasm 포함)을 그대로 긁어 가 트래픽만 쓴다. index.html 의
# <meta name="robots"> 와 _headers 의 X-Robots-Tag 가 "이미 받아 간 것을 색인하지
# 말라"고 말한다면, 이 파일은 "받아 가지도 말라"고 먼저 말하는 자리다.
#
# robots.txt 는 규약이지 강제가 아니다. 지키는 수집기만 멈춘다 — 이름을 숨기거나 이
# 파일을 아예 읽지 않는 쪽은 여기서 막히지 않는다. 그쪽은 Cloudflare 의 봇 차단이
# 볼 몫이고, 여기서는 "예의를 지키는 수집기는 전부 돌려보낸다"까지만 한다.

User-agent: *
Disallow: /

# 아래 목록은 위의 * 그룹과 내용이 같다. 그럼에도 이름을 하나씩 적는 이유는, 크롤러가
# 자기 이름이 적힌 그룹을 찾으면 * 그룹을 아예 읽지 않기 때문이다 — 규약이 "가장 구체적인
# 그룹 하나만 따른다"고 정해 두었다. 지금은 둘이 같지만, 나중에 * 쪽을 열어 주더라도
# 이 목록은 그대로 막힌 채로 남는다. AI 수집을 막는 것이 이 파일의 목적이므로
# 그 순서가 맞다.
